# Wukong Intelligence

[中文文档](./README.zh-CN.md) | English

> ✨ Let creativity travel farther—and let every image earn trust.

**Wukong Intelligence** is an AI imaging practice built around two complementary ideas: **Seventy-Two Transformations**, which helps people create and edit imagery across modalities, and **Fiery Eyes**, which helps people examine whether that imagery can be trusted.

Generative AI gives more people a visual language for imagination. It also makes it easier for manipulated images and synthetic faces to travel without context. Fiery Eyes is our response: a practical detection service that brings together several specialized models to examine global AIGC content, face forgery, and local image tampering—helping build a safer, more accountable digital space.

This repository contains the backend model code for Wukong Intelligence's detection module. It detects multiple forms of forgery, including content generated by Seventy-Two Transformations, PS tampering, and face forgery. It is developed with Flask and deploys its models locally.

The companion Vue 3 interface is available in [wukong-frontEnd](https://github.com/YueTwo/wukong-frontEnd).

## Highlights

- **Multi-signal detection** — routes media to dedicated capabilities for global AIGC content, manipulated faces, and PS/local tampering.
- **Image and video oriented** — supports the media workflows presented by the Wukong Intelligence web experience.
- **Explainable tampering review** — includes localization and visualization for PS-manipulated images.
- **Service-ready integration** — uses Flask to receive forwarded requests, obtain media from Alibaba Cloud OSS, run the appropriate model, and return detection results.
